## How to read

Per direction:
- Tasks affected ≥5 → real signal, investigate further
- 1-4 affected → marginal, overfitting risk if we tune for it
- 0 affected → drop direction entirely

For coupling:
- C1 same-code-rate > 40% → Planner-side response discipline IS the right next investment (Reflexion / N-temp / stuck-detection)
- C1 < 20% → Planner generally adapts; coupling is fine; bottleneck is elsewhere
- C2 high while C1 low → Planner changes code but doesn't fix root cause; suggests guidance quality is the bottleneck (back to Judge)
